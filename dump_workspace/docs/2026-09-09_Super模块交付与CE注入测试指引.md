3. 等 10–60 秒，读 `dump_workspace\inject_test\out\log.txt` 与 `dump.cs`。

1. 用 **Super 变体**启动（`GameAssembly_Super.dll`）。

## 3. 日志读法（出问题只看这几行）

| 标记 | 期望 | 异常含义 |
| --- | --- | --- |
| `[0] module=... base=... how=...` | 找到模块 | 找不到 → 模块名/保护方式变了 |
| `[0] bootstrap exports: available/absent` | 普通体=available，Super=absent | 与变体不符 → 注入到了另一个变体 |
| `[0] super mode: ... pure memory scan` | 仅 Super 出现 | — |
| `[scan] regions=... klasses found=N` | N ≈ 全部类数（本次实测 56214 量级） | N=0 → 结构被重排，需看 `[cal]` |
| `[cal] fields/methods/props` | 分数 > 0（普通体实测 36/96、62/96、20/96） | 全 0 → 结构布局变化 |
| `[cal] flags off=... token off=...` | **本次新增**：应为 0x110/0x114 | 若报 0x108 说明目标真的是标准布局 |
| `[cal] iface_count off=...` | 应为 0x124 | 若仍是 0x11C → 接口未校准 |
| `[cal] parammode ... -> mode=N` | **本次新增**：0=紧凑, 1=ParameterInfo@0x10 | — |
| `[cal] typedata ... -> mode=pointer/index` | **本次新增**：index 表示 data 是类型索引 | — |
| `[1] images = N` | 124（普通体实测） | 远小于 → 镜像发现退化 |
| `[2] dumping '<image>' ...` | 逐个镜像 | 中断 → 被反作弊踢出 |
| `[3] DONE classes=... fields=... methods=...` | 类数 ≥ 56214 | 明显变小 → 提前退出 |
| `[4] result=OK` | OK | FAIL/缺失 → 未完成 |

旧产物基线（2026-09-09 13:40 实测，73.1 MB）：

| 指标 | 旧值 | 期望（新版） |
| --- | --- | --- |
| images / classes | 124 / 56214 | 不低于旧值 |
| internal 占比 | **100%** | 大幅下降（多数类应为 public/sealed） |
| `[Serializable]` | **0** | > 0（应为数千） |
| 基类/接口行 · 重复项 · 垃圾项 | 26417 · 1888 · 8081 | 重复/垃圾 ≈ 0 |
| 类型名退化 ` Class ` | **259670** | 接近 0 |
| 类型名退化 `Type0` | 9079 | 接近 0 |
| 参数名 合成/真实 | 10014 / 234023 | 合成占比不升高 |

对应修复：

1. **flags/token 自动校准**（修 internal 全错 + `[Serializable]`=0）
2. **interfaces 数组/计数校准 + 计数字段互斥 + 输出去重过滤**（修基类/接口垃圾）
3. **`Il2CppType.data` 指针/索引双语义 + 索引表回查**（修 `Class`/`Type0` 退化）
4. **参数布局全局一次性判定**（修参数类型错乱，不再逐参猜）
5. **metadata 定位加"无魔数"结构化兜底**：上一版实机 `[meta] not found`，因为本构建
   内存里的 metadata 头部魔数被改写。新版在魔数扫描失败后再做一遍结构化定位，
   只用「stringOff + nameIndex 必须精确等于类名」这条强约束（误判概率可忽略）。
6. **安全读优化**：区域缓存不再对已缓存区域重复 VirtualQuery
   （旧实测 `vq=17430430`，合成端到端已降到 `166184` 量级）
7. **Super 无导出引导**：全内存 klass 扫描 + `klass->token` 还原 TypeDefinitionIndex
   + `klass->image` 推导镜像（新能力）

## 5. 已知限制 / 注意事项

- **Super 扫描耗时**：要遍历目标进程全部可读区域。游戏约 3.5 GB 时预计数秒到十几秒，
  期间若被 NEAC 踢出，日志会停在 `[scan]` 行。建议与普通体一样在登录界面注入。
- **Super 的 RVA**：以找到的模块基址为基准。若 VMP 把原代码映射到别处，
  `// RVA:` 可能不是文件内偏移（VA 仍然有效）。
- **参数名**：优先 metadata；找不到时用运行时 `ParameterInfo` 名；再不行合成 `pN`。
  合成占比会在 `[3] synthParams=` 里统计。
- **`out` vs `ref`**：由参数类型 attrs 的 Out 位判断（cfg `outheuristic=1`，默认开）。
- **配置回退**：`SuperDumper.cfg` 不存在时会依次回退 `MemoryStructDumper.cfg` /
  `Il2CppRuntimeDumper.cfg`；都没有则输出到 DLL 同目录 `out\`。
