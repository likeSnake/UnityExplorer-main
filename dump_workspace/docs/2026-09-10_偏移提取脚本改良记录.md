# YJWJOffset_new.py：v7 内存振偏移提取与旧格式兼容

## 完成内容

已修改 `F:\gua\UnityExplorer-main\dump_workspace\inject_test\YJWJOffset_new.py`。直接兼容用户当前运行成功的 SuperDumper v7 dump，**本次无需修改 DLL，也无需重新运行 dump**。

旧脚本的几个限制：

- 只有输入行含 `Class:` 才参与处理，内存振布局常量、方法和大多数旧项没有这种注释。
- 只能替换数字初始化，不能更新 `InitActorKitRefer = MemoryShockUnresolvedRva` 和 `CrossFadeInFixedTime = AnimPlayableCrossFadeInFixedTimeNormal`。
- 没有恢复匿名嵌套结构路径，无法用变量身份匹配 `Offset::ActorModel.RuntimeLogicLayerS.LayerWeight`。
- 每处理一项都重新读整个 dump，并且同名类取第一项，既慢也容易选错。
- 字段正则使用词边界，对 `<name>k__BackingField` 不可靠；没有区分变体和候选/失败状态。

新版优先使用 v7 已有的协议：

```cpp
// Offset::MemoryShockEntityKitActorModelOffset = 0x18; // status=FOUND Class: EntityKit->ActorModel <actorModel>k__BackingField [instance]
// Offset::Il2CppClassStaticFieldsOffset = 0xB8; // status=VERIFIED singleton instance klass back-reference
// Offset::CrossFadeInFixedTime = 0x797D760; // status=FOUND ...
```

按**完整变量路径**匹配输入声明，不依赖 Class 注释。类字段、方法 RVA、TypeInfo RVA、IL2CPP 布局、Dictionary Entry 推导结果均可处理。匿名 struct 的嵌套路径从括号范围和 `} 实例名;` 恢复，函数体、注释和枚举不会被当成待更新偏移。支持 DWORD、uint64_t、uint32_t、uint16_t、uint8_t、uintptr_t 及常用限定符。

这不是完整 C++ 编译器，不执行宏、函数或初始化表达式；以当前 Offset.h 使用的声明格式为目标。无法解析为偏移的旧裸地址也不会凭空生成新值。

## 写入规则

| dump 状态 | 更新头文件的处理 |
|---|---|
| FOUND / CALIBRATED / VERIFIED / DERIVED | 数值合法且在声明类型范围内时允许更新 |
| 数值与输入相同 | UNCHANGED，保留原数字写法和空白，不制造无意义差异 |
| CANDIDATE / NOT_FOUND / UNRESOLVED / UNRESOLVED_LAYOUT / AMBIGUOUS 等 | 保留旧初始化值，并在报告中标明未确认 |
| NOT_LOADED / NOT_DUMPED | 保留另一变体，不回退取当前变体的同名 Class RVA |
| RUNTIME_VA，或模块/MatrixAddr 变量 | 报告实际值或状态，不将临时进程 VA 固化到头文件 |
| ABI_LAYOUT / CONFIG_CONSTANT | 核对并记录，保留配置/ABI 常量 |
| 未知状态 | 保留原值，不自动视为成功 |

摘要存在时，以摘要为准；摘要明确失败或某条缺失，不会转而从正文找到一个值来覆盖状态。摘要重复键、成功状态却没有数字、缺少 Inventory 或数量不符时，报错退出，不生成更新文件。

日志逐条包含：变量完整路径、输入行号、旧初始化表达式、提取值、status、action、source、证据。**保留旧值不代表旧值已通过验证**，尤其不能把 CANDIDATE 原本就等于 0x198 误算为成功更新。

输出为原文件旁的 `*_updated.h` 和指定日志，原 Offset.h、原 dump 不覆盖。可指定 `--updated` 将头文件副本输出到其他目录。保留源文件编码（测试 UTF-8/BOM、GBK、UTF-16）、CRLF、空白、注释、无末尾换行等格式。写入前检查输出路径不得与输入/dump 重合，数值不得溢出声明类型。

符号初始化可以被替换为已确认数值，例如 CrossFade 被替换为本轮 Super 的 RVA。生成结果中的此类共享变量仅代表**本次选中变体**，不是同时发现两套数值。

## 旧 dump 兼容

没有 v7 摘要时，自动走旧 `Class:` 模式。一次流式建索引，支持：

- `Class: ActorModel->ObjectMessenger objectMsg` 和仅写字段名的注释。
- backing field 自动匹配、父类查找。
- 同名类按目标字段唯一命中消歧；有多个匹配则 AMBIGUOUS。
- 精确大小写；可写 `Class: Namespace.Class->字段` 明确命名空间。
- 类级 RVA 与方法 RVA 分离，不拿下方方法 RVA 当 TypeInfo RVA。
- 静态字段 offset=0 合法；开放泛型实例字段的异常零布局不写回。

如果旧 dump 没有模块标记，`--variant auto` 不会猜普通/Super。共享字段仍可提取，但涉及变体的 TypeInfo 变量标 VARIANT_UNKNOWN。可用 `--variant normal` 或 `--variant super` 指明来源；显式选择与 dump 模块标记冲突时会拒绝处理。

旧 dump 既没有摘要、输入也没有 Class 注释的项，仍标 NO_MAPPING。要提取这类内存振项目，使用当前 v7 dump。
